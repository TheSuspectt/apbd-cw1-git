
# Ćwiczenia 1 - Git i GitHub

Projekt konsolowy w C# przygotowany na potrzeby ćwiczeń z APBD.

Program wyświetla powitanie oraz oblicza sumę, średnią arytmetyczną, liczbę elementów i maksymalną wartość w tablicy liczb.

## Uruchomienie

Wymagane jest zainstalowane .NET SDK.

Aby uruchomić program, wykonaj w katalogu projektu:

```bash
dotnet run
```
